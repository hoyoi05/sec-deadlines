한국어 버전의 변경 사항

hoyoi05/sec-deadlines는 원본을 포크한 비공식 한국어 버전입니다. 원본 학회 데이터와 태그 코드, 연구 분야·출판 유형·CORE 등급의 3개 필터 그룹을 보존하고, 연구 분야에 AI 태그를 추가했습니다. 그룹 내부 OR, 그룹 간 AND 규칙과 원본의 마감 시각 보정 규칙도 유지합니다.

화면과 필터 이름을 한국어로 번역하고, 마감일을 Asia/Seoul(KST, UTC+9)로 고정 표시하도록 변경했습니다. 명시적인 원본 시간대가 없는 기존 마감은 원본과 동일하게 AoE(UTC−12)로 해석합니다. 다만 공식 발표에 날짜만 있고 시각·시간대가 미공개인 것으로 확인된 경우 환산을 보류합니다. 원본이 분 단위로 제공하는 시각 중 00분은 1초 전으로, 59분은 해당 분의 59초로 표시하는 규칙을 따릅니다.

학회명과 공식 영문 명칭·장소는 원본 표기를 유지합니다. 개최 일정은 개최지의 날짜이며, 공식 CFP에서 확인하여 별도 필드로 추가한 초록·논문 등록 마감도 KST로 환산하며, 본문 제출 마감과 구분합니다. ‘국가 단위 / 미등급’은 원본 National/Unranked의 번역으로, 대한민국 학회만을 뜻하지 않습니다.

추가 AI 학회 데이터

{{ site.ai_cfp_checked }}에 각 공식 CFP를 직접 확인하여 ICLR, AISTATS, CVPR, AAAI, NeurIPS, ICML, IJCAI-ECAI, ACL, EMNLP, COLT, UAI, WACV의 공개된 최신 회차 일정을 추가했습니다. 각 학회 항목에 공식 CFP 링크와 확인일을 표시하며, CFP 본문을 재배포하지 않고 마감일·시간대·제출 단계 등 일정 정보만 정리했습니다. 다음 회차 일정이 미공개인 경우 이전 회차 날짜로 추정하지 않습니다.

기존 보안·AI 교차 분야 학회에는 AI 태그를 추가했습니다. SaTML의 필수 초록 등록일은 공식 CFP에서 확인했고, SAIS는 공식 페이지에서 날짜만 발표하여 시각·시간대 확인 전 KST 환산을 보류합니다. 공식 확인 링크가 없는 기존 항목은 원본 데이터를 사용하며 화면에 출처를 구분해 표시합니다.

AI 태그와 새 AI 일정은 이 한국어 버전의 추가 사항입니다. CORE 등급은 확인되지 않은 새 학회에 임의로 부여하지 않았습니다. 추가 AI 일정과 공식 출처 목록에서 확인할 수 있습니다.

라이선스 상태

2026년 9월 11일 확인한 기준 소스에는 프로젝트 전체에 적용되는 별도 LICENSE 파일이 없습니다. 원본 코드·데이터의 저작권은 각 권리자에게 있으며, 이 한국어 버전은 원본에 새로운 라이선스를 부여하거나 권리를 이전받았다고 주장하지 않습니다. 원본의 이력과 저작자 표기를 보존합니다.

출처 표시는 이용 허락을 대신하지 않습니다. 포크 외 수정·재배포에 필요한 권한은 원저작권자에게 별도로 확인해야 합니다. GitHub의 저장소 라이선스 안내를 참고하세요.
